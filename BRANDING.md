# mlinux brand

## Name
**mlinux** (always lowercase). Short for "Mac Linux". Not affiliated with Apple, Asahi Linux, Gravity Linux or Omarchy.

> Before publishing: search for existing projects named "mlinux" and check the trademark and domain situation. Pick a different name if there is a clash.

## Tagline
**Linux, native on Apple Silicon.**

Alternates: "Your Mac, booted your way." / "Boot it yourself."

## Voice
Plain, honest, builder-to-builder. Never claim hardware works until it has been verified on real hardware. "Works", "untested" and "broken" are the only three states we use.

## Type
Headings and logo: a geometric sans (Inter or system UI). Code and terminal: JetBrains Mono or system monospace.

## Logo
`assets/logo.svg`: a rounded square holding a stylised "m" (two arches) and a boot-prompt cursor underneath. Use on dark backgrounds. Keep clear space equal to the cursor height. Don't recolour, rotate or add effects.

## Hardware status badges
Use these in docs, worded exactly:
- `works`: verified on real hardware, with the date and kernel version
- `untested`: should work in theory, nobody has tried
- `broken`: tried and failed, link the issue

## Credit and attribution
mlinux builds on others' work. Keep every upstream licence and credit (see CREDITS.md). Don't use the Asahi Linux, Gravity Linux or Omarchy names or logos as ours.
